## 🔌 Интегрированные API endpoints

### Полностью рабочие endpoints:
```
✅ POST   /api/applications                    - создание заказа
✅ GET    /api/applications/:id                - получить заказ
✅ PATCH  /api/applications/:id                - обновить статус
✅ GET    /api/applications/:id/responses      - получить отклики
✅ POST   /api/applications/:id/respond        - отправить отклик
✅ POST   /api/applications/:id/reviews        - создать отзыв
✅ GET    /api/users?role=specialist          - получить специалистов
✅ GET    /api/users/:id                       - профиль пользователя
✅ GET    /api/users/:id/reviews              - отзывы пользователя
✅ POST   /api/conversations                   - создать беседу
✅ GET    /api/conversations/:id/messages      - получить сообщения
✅ POST   /api/conversations/:id/messages      - отправить сообщение
```

## 📱 Основные workflows

### Workflow для заказчика:
1. **Home.js** → "Создать заявку"
2. **CreateApplicationScreen** → заполнить форму → POST
3. **OrdersHistoryScreen** → выбрать заказ → ApplicationDetail
4. **ApplicationDetailScreen** → просмотр откликов (кнопка)
5. **ResponsesViewScreen** → выбрать специалиста → просмотр профиля или чат
6. **SpecialistProfileView** → информация о специалисте
7. **ChatScreen** → переписка
8. **ApplicationDetailScreen** → изменить статус → завершить → оставить отзыв

### Workflow для специалиста:
1. **HomePro** → "Доступные заказы" или "Лента заявок"
2. **AvailableApplicationsScreen** → поиск заказов
3. **Модальное окно** → отправить отклик
4. Ожидание ответа заказчика
5. **ChatScreen** → переписка с клиентом

### Workflow поиска специалиста:
1. **Home.js** → "Каталог специалистов"
2. **SpecialistsCatalogScreen** → поиск по имени
3. **Фильтры** → город + категории
4. **Карточка** → просмотр профиля или чат
