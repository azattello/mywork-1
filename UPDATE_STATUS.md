## 🔧 ЧТО БЫЛО ИСПРАВЛЕНО

### 1. ❌ → ✅ apiClient - добавлены методы get/post/patch/delete

**Файл:** `utils/apiClient.js`

**Проблема:** Компоненты вызывали `apiClient.get()`, `apiClient.post()` и т.д., но в apiClient был только метод `request()`

**Решение:** Добавлены convenience methods:
```javascript
get: async (path, config = {}) => client.request('get', path, null, config)
post: async (path, data, config = {}) => client.request('post', path, data, config)
patch: async (path, data, config = {}) => client.request('patch', path, data, config)
delete: async (path, config = {}) => client.request('delete', path, null, config)
```

**Результат:** Теперь код вроде `apiClient.get('/api/users?role=specialist')` работает корректно ✅

### 2. ❌ → ✅ CreateApplicationScreen - исправлена ошибка 400

**Файл:** `components/CreateApplicationScreen.js`

**Проблема:** Отправлялся `categories: []` массив, но бэкенд ожидает `mode: "строка"`

**Решение:** Изменен payload:
```javascript

categories: form.categories,

// ✅ Стало
mode: form.categories[0] || '',
```

**Результат:** Заказы теперь создаются успешно без ошибки 400 ✅

## 💬 ВОЗМОЖНЫЕ ОШИБКИ ПРИ ТЕСТИРОВАНИИ

### Ошибка: "Cannot find route"
→ Убедитесь что все Stack.Screen маршруты добавлены в Main.js

### Ошибка: "apiClient.get is not a function"
→ Убедитесь что используете правильный импорт: `import apiClient from '../utils/apiClient'`

### Ошибка: "Cannot read property '_id' of undefined"
→ Убедитесь что пользователь залогинен и @currentUser есть в AsyncStorage

### Ошибка 400 при создании заказа
→ Уже исправлено! Теперь отправляется `mode` вместо `categories`

### Список не загружается (пусто)
→ Вероятно 2 причины:
1. Backend не отправляет данные - проверить бэкенд логи
2. Неправильный API_URL в config.js - проверить IP
