## Полный workflow заказчика теперь:

```
1. Вход в систему → Home.js (проверка роли)
                  ↓
2. Главная → HomeCustomer (статистика + быстрые действия)
             ├─ Создать заказ
             ├─ Найти специалиста
             ├─ Мои заявки
             └─ Чаты
3. Создать заказ → CreateApplicationScreen
4. Каталог специалистов → SpecialistsCatalogScreen
5. Мои заявки → MyApplicationsScreen
6. Чаты → ChatListScreen
   └─ Открыть чат → ChatScreen
7. Профиль → Account
```
