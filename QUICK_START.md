# 🚀 БЫСТРЫЙ СТАРТ

## Что было реализовано
✅ **Функция разблокировки специалиста в чате**

Специалист может просматривать сообщения ТОЛЬКО после того, как клиент отправит ПЕРВОЕ сообщение.

---

## Запуск

### Backend
```bash
cd backend
npm run dev  # nodemon будет перезагружать при изменениях
```
Сервер запустится на `http://localhost:4000`

### Frontend
```bash
npm start
```
Приложение запустится на `http://localhost:19006`

---

## Быстрый тест (2 минуты)

1. **Откройте два браузера** (или два устройства)
   - Браузер 1: Роль = "Клиент" (User)
   - Браузер 2: Роль = "Специалист" (Specialist)

2. **Клиент**: Создайте заявку (AppsScreen → AddScreen)
   - Заголовок: "Тест"
   - Бюджет: 1000
   - Сохраните

3. **Специалист**: Найдите заявку (AvailableApplicationsScreen)
   - Нажмите "Отправить предложение"

4. **Клиент**: Перейдите в ResponsesViewScreen
   - Нажмите "Чат" на предложении специалиста

5. **Специалист**: Откройте чат
   - ❌ Вы должны увидеть: **[🔒 Доступ закрыт]**
   - ⏳ Ждите сообщения от клиента

6. **Клиент**: Напишите сообщение (например, "Привет!")
   - Нажмите отправить

7. **Специалист**: Смотрите чат
   - ✅ Должно обновиться автоматически
   - ✅ Вы увидите все сообщения
   - ✅ Сможете ответить

## Как это работает

```javascript
// Когда клиент отправляет сообщение:
if (messageCount === 1 && req.user.role === 'user') {
  // 1. Установить флаг разблокировки
  conversation.specialistUnlocked = true;
  
  // 2. Отправить уведомление специалисту
  io.to('user_' + specialistId).emit('unlock_chat', {...});
}

// Когда специалист пытается загрузить сообщения:
if (req.user.role === 'specialist' && !specialistUnlocked) {
  // Вернуть ошибку 403 "Доступ запрещен"
  return res.status(403).json({...});
}

// На фронтенде специалиста:
socket.on('unlock_chat', () => {
  setAccessDenied(false); // Убрать блокировку
  loadMessages();         // Загрузить сообщения
});
```

## Возможные проблемы

### Проблема: Специалист все еще видит "Доступ закрыт"
**Решение**: Убедитесь, что сообщение действительно было отправлено (статус 201 в Network tab)

### Проблема: Ошибка "listen EADDRINUSE"
**Решение**: Порт 4000 занят. Либо закройте другой процесс, либо используйте другой порт

### Проблема: Socket.io событие не приходит
**Решение**: Убедитесь, что специалист присоединился к room `user_{specialistId}` при входе в приложение
