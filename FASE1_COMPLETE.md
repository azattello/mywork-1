## Итоговая архитектура (Fase 1):

### Workflow заказчика:
1. **Home.js** → кнопка "Создать заказ"
2. **CreateApplicationScreen** → заполнить форму → POST /api/applications
3. **OrdersHistoryScreen** → список своих заказов → кнопка "Просмотр откликов"
4. **ResponsesViewScreen** → список откликов → выбрать специалиста
5. **ChatScreen** → переписка с выбранным специалистом

### Workflow специалиста:
1. **HomePro** → кнопка "Доступные заказы"
2. **AvailableApplicationsScreen** → поиск заказов → "Отправить отклик"
3. **Modal** → заполнить отклик → POST /api/applications/:id/respond
4. **ChatScreen** → ожидание ответа заказчика
