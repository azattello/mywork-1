# Smoke test — Account (Client & Specialist)

## Подготовка
- Убедитесь, что backend запущен: `cd backend && npm run dev` (или запустить через nodemon)
- Убедитесь, что мобильное приложение запущено через Expo: `npx expo start` (или используй устройство/эмулятор)
- Для тестирования API можно использовать `curl` или Postman. Примеры ниже.

## Тестовые данные
- Тестовый пользователь: зарегистрируй нового пользователя через экран регистрации
- Тестовое изображение: небольшой PNG/JPG < 1MB

---

## Шаги (фронтенд)

1. Регистрация
   - Открой экран регистрации
   - Заполни имя, фамилию, телефон и пароль (>= 6 символов)
   - Нажми «Регистрация» — ожидаемый результат: переход в главный экран, токены сохраняются в AsyncStorage

2. Просмотр профиля
   - Перейди в `Аккаунт` (Client)
   - Ожидаемый результат: отображается имя/фамилия и аватар (по умолчанию)

3. Редактирование профиля и загрузка аватара
   - Нажми «Настройки аккаунта» → «Загрузить аватар»
   - Выбери изображение (валидное)
   - Должен появиться индикатор загрузки (spinner) и прогресс
   - После успешной загрузки — toast "Аватар обновлен" и аватар обновится
   - Попробовать загрузить большой файл (>5MB) — ожидание: toast с ошибкой ("Файл слишком большой")
   - Попробовать загрузить файл с неправильным mime — ожидание: toast "Разрешены только изображения"

4. Изменение имени/фамилии
   - Отредактировать и сохранить — ожидание: toast "Профиль сохранён" и данные обновлены

5. Режим специалиста (Pro)
   - Переключиться в режим специалиста → открой профиль Pro
   - Найти переключатель "Готов к новым заказам" и переключить
   - Ожидаемый результат: toast при успехе или откат и toast с ошибкой при неудаче

6. Проверка авторизации
   - Выйти (кнопка «Выйти из аккаунта»)
   - Попробовать доступ к защищённому endpoint (профиль) — ожидание: перенаправление на вход или 401

---

## Шаги (бэкенд / curl)

- Получить профиль (заменить <TOKEN>):
  curl -H "Authorization: Bearer <TOKEN>" http://localhost:3000/api/users/me

- Обновить профиль (пример):
  curl -X PUT -H "Content-Type: application/json" -H "Authorization: Bearer <TOKEN>" -d '{"name":"New"}' http://localhost:3000/api/users/me

- Загрузить аватар (пример):
  curl -X POST -H "Authorization: Bearer <TOKEN>" -F "avatar=@/path/to/file.png" http://localhost:3000/api/users/me/avatar
