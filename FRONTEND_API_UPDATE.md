# 📱 Обновление фронтенда для подключения к VPS

## Где находится конфиг API?

В твоем React Native проекте найди файл, где определена переменная API URL.
Обычно это:

1. `constants.js` или `config.js` в корне проекта
2. `utils/api.js` или `api/client.js`
3. В переменной окружения `.env`

## Как найти текущий API URL?

```bash
# Поиск в проекте
grep -r "API_URL\|http://172\|localhost" frontend/ --include="*.js" --include="*.jsx" --include="*.ts" --include="*.tsx"

# или в Windows (PowerShell)
Get-ChildItem -Path ".\components", ".\utils" -Recurse -Include "*.js" | Select-String -Pattern "API_URL|http://172|localhost"
```

## Варианты обновления

### Вариант 1: Если используешь файл конфига

Найди файл типа `config.js` или `constants.js`:

```javascript
// ДО (было):
export const API_URL = 'http://172.20.10.2:4000';

// ПОСЛЕ (станет):
export const API_URL = 'http://194.32.142.33:4000';

// Или если потом будет SSL и домен:
// export const API_URL = 'https://your-domain.com';
```

### Вариант 2: Если используешь переменную в каждом файле

Замени все вхождения:
- `http://172.20.10.2:4000` → `http://194.32.142.33:4000`
- Или используй конфиг файл (Вариант 1)

### Вариант 3: Если используешь .env файл

```bash
# .env файл в корне frontend
API_URL=http://194.32.142.33:4000

# или с доменом (потом)
# API_URL=https://your-domain.com
```

## Проверка после обновления

1. **Перезагрузи Expo:**
   ```bash
   # В терминале где запущен Expo
   Press r  # перезагрузить приложение
   # Или нажми 'r' в терминале
   ```

2. **Проверь в логах Expo:**
   Должны появиться запросы к `http://194.32.142.33:4000`

3. **Протестируй функциональность:**
   - Вход в аккаунт
   - Загрузка данных профиля
   - Загрузка приложений
   - Отправка сообщений (chat)

## Если что-то не работает

### Проверить подключение к API

```bash
# На локальной машине
curl http://194.32.142.33:4000/api/health

# Если ответит:
# {"status":"ok"} - API работает! ✅

# Если нет ответа:
# 1. Проверь IP адрес правильный
# 2. Проверь что приложение запущено на VPS: pm2 status
# 3. Проверь логи на VPS: pm2 logs mywork-api
```

### Если Android/iOS не подключается

Проблема может быть в firewall на VPS:

```bash
# На VPS проверить открыт ли порт
netstat -tuln | grep 4000

# Открыть порт (если закрыт)
ufw allow 4000/tcp
ufw enable
```

## Полная цепочка обновления

1. **Отредактируй конфиг фронтенда:**
   ```javascript
   export const API_URL = 'http://194.32.142.33:4000';
   ```

2. **Сохрани файл и перезагрузи Expo:**
   ```
   Press r в терминале Expo
   ```

3. **Проверь логи в Expo:**
   Должны видеть запросы к новому адресу

4. **Протестируй приложение:**
   - Авторизация
   - Загрузка данных
   - API запросы

## 🚀 После развертывания со SSL (в будущем)

Когда настроишь Nginx + SSL сертификат на VPS:

```javascript
// Обнови на:
export const API_URL = 'https://your-domain.com';
```

Тогда приложение будет работать с защищенным соединением!
